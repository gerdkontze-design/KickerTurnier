# Kicker Turnier

Minimal offline React app to run a table-soccer (Kicker) tournament. Data is stored in the browser `localStorage`.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

Open http://localhost:5173 in your browser.

Notes
- Configure number of tables and player names on the setup screen.
- Enter results directly in the Begegnungen list; standings update live.
- The app is intentionally minimal and stores the tournament state in `localStorage`.
